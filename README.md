# Diablo Travieso · Editorial Independiente

Sitio web oficial de **Editorial Diablo Travieso** (Costa Rica): literatura independiente de terror, horror psicológico y realismo extraño.

## Tecnologías
- HTML5 + CSS3 + JavaScript puro (sin frameworks)
- Fuentes: [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue) & [Lora](https://fonts.google.com/specimen/Lora)
- Diseño brutalista black & white con acentos en óxido y rojo sangre.
- Totalmente responsive con menú hamburguesa, modales editoriales y formulario de contacto.

## Estructura de archivos
```
/
├── index.html                           # Página principal
├── logo.png                             # Sello oficial (favicon + logos)
├── portada la brujeria es pan del cielo.jpg
├── aveces pasan cosas raras_.jpg
├── portada el noveno piso.jpg
├── portada la vela roja.jpg             # (opcional: portada Nº1 Librería del Terror)
├── El noveno piso (DTLT N2).pdf         # PDF descargable
└── README.md
```

## Secciones
1. **Home / Hero** — Logo circular y última novedad (*El noveno piso*).
2. **Quiénes somos** — Filosofía editorial.
3. **Tienda Editorial** — Libros impresos con enlaces a Amazon y WhatsApp.
4. **Librería del Terror** — Relatos digitales en PDF.
5. **Artículos** — Ensayos literarios.
6. **Contacto** — Formulario editorial.
7. **Footer** — Redes, contacto, enlaces legales.

## Cómo subir a GitHub
1. Crea un nuevo repositorio público o privado en GitHub.
2. Sube el `.zip` que generes (ver instrucciones abajo) o haz `git push` de la carpeta.
3. Para publicar el sitio en GitHub Pages: ve a *Settings → Pages* y selecciona la rama `main` / carpeta raíz.
